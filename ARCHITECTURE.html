🎯 Présentation de la Solution

PortaLis est une plateforme web moderne de gestion commerciale et de transport, conçue pour les entreprises utilisant Odoo comme ERP. Elle centralise la gestion des opportunités commerciales, automatise la génération d'offres de transport via IA, et fournit un tableau de bord KPI performant pour piloter l'activité.

🚀 Fonctionnalités du MVP

1. Gestion des Opportunités Commerciales

Pipeline Structuré

Suivi complet : Nouveau → Contacté → Qualifié → Converti / Perdu avec synchronisation automatique vers Odoo

Recherche Intelligente

Recherche multi-champs sur entreprise, contact, email, notes et secteur pour retrouver rapidement vos opportunités

Actions Synchronisées

Chaque action (contact, qualify, convert, lose) est répercutée en temps réel dans Odoo crm.lead

Notes & Compte-rendus

Annotation des opportunités et génération de compte-rendus PDF stockés sur MinIO

2. Offres de Transport Assistées par IA

Conversation Naturelle

Interagissez avec Claude AI pour collecter les données (client, trajet, produit) en langage naturel

Génération Automatique

Création automatique de dossiers transport.shipment dans Odoo après validation de l'offre

Modes Multiples

Support terrestre, maritime, aérien et multimodal avec calculs automatiques de prix

Parsing Dates Intelligent

Compréhension des dates en français (demain, vendredi, dans 3 jours) pour une expérience fluide

3. Tableau de Bord KPI

Indicateurs Prédéfinis

CA mensuel, marge globale, ponctualité, dossiers par statut, statistiques globales

Calcul Parallèle

Optimisation performance via calculs asynchrones pour un affichage instantané

Gestion des Accès

Contrôle d'accès par groupes Keycloak avec bypass admin pour les super-administrateurs

Configuration Flexible

Interface dédiée pour configurer les KPIs accessibles par chaque groupe d'utilisateurs

🏗️ Architecture Technique

Stack moderne et robuste, conçue pour l'évolutivité et la performance :

FastAPI (Backend) Next.js (Frontend) Odoo ERP (Intégration) Keycloak (Auth) PostgreSQL (BD) MinIO (Stockage) Celery (Tâches) Claude AI (IA)
